# v1.2.0 — 遥控器麦克风增益

## 新增

- 解码后增加与“无线麦”一致的语音后处理：
  - 20 Hz 一阶高通，去掉 ADPCM 预测器带来的 DC 偏置；
  - `[1,2,1]/4` 三点平滑；
  - dB 增益，默认 **+10 dB**，范围 -24..+24 dB；
  - int16 削波保护。
- 增益设置合并进主 App：**Google TV Remote → 设置 → 麦克风增益**，滑块 + 预设，
  写入 `~/Library/Application Support/gvtv-remote/mic-config.json`，下一次按住语音键生效。
- 新增 `scripts/set-gain.sh <dB>`，方便命令行调整。
- 桥在每次语音会话开始时重新读取配置并打印 `增益 +xx.x dB`，便于确认。

## 验证

- 默认 +10 dB 时音量约提升 3.16 倍；
- 实测 +13 dB、虚拟麦克风峰值约 0.71，输入法识别明显更稳；
- 不改变按需虚拟管道与休眠/唤醒行为。
- 修复 `install-app.sh` 在 `/Applications` 已存在旧 App 时会嵌套复制的问题，现在会先退出并替换。

> 注意：重建主 App 后 macOS 会重置一次「输入监控 / 辅助功能」权限，重新勾选即可；
> 本地已合并，不再需要单独的 MicGain.app。

## 使用

- 打开主 App 的「设置 → 麦克风增益」调整，或 `./scripts/set-gain.sh 13`；
- 建议 6–14 dB；过高会放大底噪/削波。
