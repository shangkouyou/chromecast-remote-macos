# v1.2.1 — 蓝牙耳机语音输入修复

## 修复

- 连接带麦克风的蓝牙耳机（如 Baseus Bowie MC1）后，Chatterfly 会优先使用耳机麦克风，
  导致按遥控器语音键时输入法听不到虚拟麦克风、无法上屏。
- 新增 `scripts/set-ime-mic.sh`：把 Chatterfly 的 `kSGSpeechAudioInputDeviceUID`
  固定为 `Google TV2ch_UID`，并重启输入法；`scripts/install-mic.sh` 会自动执行一次。
- 保持按需虚拟管道：戴/不戴耳机、手动切换输入输出，都不再影响语音。

## 验证

- 连接 Baseus 耳机、系统输出=耳机、系统输入=`Google TV 2ch`，按住语音键正常上屏；
- 不戴耳机同样正常；
- 虚拟麦克风 RMS/峰值正常，未出现削波。

## 升级

```bash
git pull
./scripts/set-ime-mic.sh "Google TV 2ch"
```

如果使用其它输入法，请在其麦克风设置里手动选择 `Google TV 2ch` / `BlackHole 2ch`。

> 仓库已统一改名为 `chromecast-remote-macos`（GitHub 与 CNB）。
