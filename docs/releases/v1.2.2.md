# v1.2.2 — 语音输入稳定性

## 变化

- 音频桥收到语音键按下（`0x08`）时**预打开**虚拟管道，减少“输入法先开麦、桥后开管道”
  导致首句丢失的竞态。
- 新增 `scripts/repair-voice.sh`：一键重启麦克风桥和输入法，清理长时间运行/休眠后
  卡住的 CoreAudio 会话。
- 文档补充：语音不上屏时先再按一次；仍不行运行修复脚本。

## 使用

```bash
./scripts/repair-voice.sh
```

戴蓝牙耳机时如仍被输入法抢麦克风，再执行：

```bash
./scripts/set-ime-mic.sh "Google TV 2ch"
```

## 说明

虚拟麦克风本身有波形（RMS≈0.03、峰值≈0.8），问题多在输入法的音频会话状态；
重启桥 + 输入法即可恢复，不需要重新安装系统组件。
